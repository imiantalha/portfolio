## Running Locally

### Prerequisites

- Node.js 18+
- npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Then open `http://localhost:3000` in your browser.

### Production Build

```bash
npm run build
npm start
```

The portfolio is deployed on Vercel.
